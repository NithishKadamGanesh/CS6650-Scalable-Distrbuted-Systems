## Step-by-Step Execution Guide

### Prerequisites
- AWS CLI configured (`aws configure` with your credentials/session token)
- Docker Desktop running (for image build + push)
- Terraform installed
- Go 1.24+ installed
- Python 3.x installed (for test scripts)

---

### STEP 3: Deploy Infrastructure

```bash
terraform apply -var="db_password=YourSecurePass123!"
```

**What this creates (in order):**
1. **ECR repository** — `hw8_ecommerce`
2. **Network** — Default VPC, subnets, security group (port 8080 open)
3. **RDS MySQL** — `db.t3.micro` in private subnets, security group allows port 3306 from ECS SG only
4. **CloudWatch log group** — `/ecs/hw8-store`
5. **Docker image** — Builds from `../src`, pushes to ECR
6. **ECS Fargate task** — Runs your container with DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD injected as environment variables

⏱ **RDS takes 5-10 minutes to provision.** Be patient.

When `terraform apply` finishes, note the outputs:
```
rds_endpoint = "hw8-store-mysql.xxxx.us-east-1.rds.amazonaws.com:3306"
rds_hostname = "hw8-store-mysql.xxxx.us-east-1.rds.amazonaws.com"
ecs_cluster_name = "hw8-store-cluster"
ecs_service_name = "hw8-store"
```

---

### STEP 4: Find Your ECS Task's Public IP

```bash
# Get the task ARN
aws ecs list-tasks --cluster hw8-store-cluster --service-name hw8-store --region us-east-1

# Describe it to find the ENI
aws ecs describe-tasks --cluster hw8-store-cluster --tasks <TASK_ARN> --region us-east-1
```

Look for `networkInterfaces` → `privateIpv4Address`. Since `assign_public_ip = true`, you can find the public IP by:

```bash
# From the task description, find the ENI attachment ID, then:
aws ec2 describe-network-interfaces --network-interface-ids <ENI_ID> --region us-east-1
```

Or use the AWS Console: **ECS → Clusters → hw8-store-cluster → Tasks → click task → Networking tab → Public IP**.

Let's call this `<ECS_IP>`.

---

### STEP 5: Verify the Server is Running

```bash
# Health check (confirms MySQL connection is alive)
curl http://<ECS_IP>:8080/health

# Expected: {"status":"healthy"}
```

If you get connection refused, check CloudWatch logs:
```bash
aws logs tail /ecs/hw8-store --follow --region us-east-1
```

Common issues:
- RDS not yet available → logs show "Waiting for MySQL (attempt X/30)"
- Security group misconfigured → connection timeout after 30 attempts

### STEP 6: Manual Smoke Test

```bash
# Create a cart
curl -X POST http://<ECS_IP>:8080/shopping-carts \
  -H "Content-Type: application/json" \
  -d '{"customer_id": 1}'
# Expected: {"shopping_cart_id": 1}

# Add item to cart
curl -X POST http://<ECS_IP>:8080/shopping-carts/1/items \
  -H "Content-Type: application/json" \
  -d '{"product_id": 42, "quantity": 3}'

# Get cart with items
curl http://<ECS_IP>:8080/shopping-carts/1
# Expected: {"cart_id":1,"customer_id":1,"items":[{"item_id":1,"product_id":42,"quantity":3,...}],...}

# Add same product again (should increase quantity to 6)
curl -X POST http://<ECS_IP>:8080/shopping-carts/1/items \
  -H "Content-Type: application/json" \
  -d '{"product_id": 42, "quantity": 3}'

curl http://<ECS_IP>:8080/shopping-carts/1
# Expected: quantity is now 6

# HW5 product endpoints still work
curl -X POST http://<ECS_IP>:8080/products \
  -H "Content-Type: application/json" \
  -d '{"product_id":1,"sku":"TEST-1","manufacturer":"ACME","category_id":1,"weight":100,"some_other_id":1}'
# Expected: 201 Created
```

## API Endpoints Summary

| Method | Path | Description | Storage |
|--------|------|-------------|---------|
| POST | `/products` | Create product | In-memory |
| GET | `/products/{productId}` | Get product | In-memory |
| POST | `/products/{productId}/details` | Update product | In-memory |
| **POST** | **`/shopping-carts`** | **Create cart** | **MySQL** |
| **GET** | **`/shopping-carts/{id}`** | **Get cart + items** | **MySQL** |
| **POST** | **`/shopping-carts/{id}/items`** | **Add/update item** | **MySQL** |
| GET | `/health` | Health check + DB ping | - |

| Product storage | In-memory map | In-memory map (unchanged) |

| ECS task env vars | None | DB_HOST, DB_PORT, DB_NAME, DB_USER, DB_PASSWORD |
| Network outputs | subnet_ids, security_group_id | + **vpc_id** (needed by RDS) |
| Go dependencies | gorilla/mux | gorilla/mux + **go-sql-driver/mysql** |
